Privacy Policy

Last updated: August 4, 2026

KDP Quick Insights is a Chrome extension for Amazon KDP research. This policy explains what data we access, what we store, and what we do not do.

Data We Do Not Collect

We do not collect, store, or transmit:

  • Personally identifiable information (name, email, address, age, ID)
  • Payment or financial information
  • Passwords or authentication credentials
  • Browsing history
  • Location data
  • Health information

Data We Access Locally

The extension reads the Amazon product page you are currently viewing to extract publicly visible data: Best Sellers Rank, price, format, star rating, review count, and title. This processing happens entirely in your browser. Raw page content is not stored or transmitted.

Data We Store

Using Chrome's local storage (chrome.storage.local), we store only:

  • User preferences — e.g., native-currency display setting
  • Tracked books — rank, price, review count, and rating history for books you explicitly choose to track
  • License status — whether your Pro license is active (verified via Gumroad)

This data never leaves your device. It is not synced, sold, or shared with third parties.

External API Calls

The extension makes two types of network requests:

  • Amazon autocomplete — to fetch keyword suggestions for KDP research
  • Gumroad API — solely to verify Pro license keys

No personal data is sent in these requests.

Clipboard Access

The extension writes to your clipboard only when you explicitly click a "Copy" button (e.g., copy ASIN, copy keywords, copy CSV). This is never automatic.

Your Rights

You can clear all stored data at any time by:

  • Clicking the extension's "Clear Data" option, or
  • Removing the extension from Chrome, which deletes all associated local storage automatically
